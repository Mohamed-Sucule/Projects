QR codes

Type a link, some text, a Wi-Fi password or an email and it is a QR code before you finish typing. The encoder is written from scratch.

Launch QR codes ↗ Engineering case study Source

The problem

Most QR generators are web services. This one is written from scratch and nothing leaves the page.

Evidence

Tick “show how it is built”: most of a QR code is not your data. Read its tests

What it does

  • A link, text, Wi-Fi details or an email becomes a QR code as you type
  • Encoder and error correction written from scratch
  • Warnings before you print a code phones will struggle with

The most interesting decision

Free robustness

If the text fits at a stronger error-correction level without making the code any bigger, it takes the stronger level and says so.

Built with

  • QR encoder from scratch
  • Reed–Solomon error correction
  • SVG + PNG export
