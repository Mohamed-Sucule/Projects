Tally

An AI accounts-payable analyst. It reads supplier contracts and the accounts, answers questions with cited sources, audits every invoice against the contract and drafts the dispute emails a person approves.

Engineering case study Source See its world in the atlas

Tally is a Python service rather than a page, so it runs on a server. It deploys in one step from render.yaml; until then, the case study and the source are the way in.

The problem

Supplier invoices get paid without anyone checking them against the contract, so overcharges go through.

What it does

  • Answers questions from contracts and accounts, with every quote checked against its source
  • Audits every invoice line against the contract terms in force on its date
  • Drafts dispute emails that a person approves before anything is sent

The most interesting decision

The model reads; plain code decides what is owed

Claude extracts contract terms and answers questions, but whether a supplier overcharged is worked out by deterministic Python, tested to the penny against 23 planted errors. No note written on an invoice can talk it out of a finding.

Built with

  • Python
  • FastAPI
  • Claude API: tools + structured outputs
  • SQLite FTS5
  • Read-only SQL sandbox
  • Docker

Evidence

23 of 23 planted billing errors found to the penny, no false positives; 20 of 20 SQL attacks blocked. The model evals run once an API key is added. Read its tests

Its world

A counting-house whose roof is an open ledger. Invoices spill off its edge; a lens checks each one.
