The problem

One rule, no tutorial, and every sloppy drop carried into the next.

Evidence

The tower stays exactly as wide as you are precise. Read its tests

What it does

  • One rule: whatever overhangs is sliced off
  • A near-perfect drop gives a little width back
  • A run takes about two minutes

The most interesting decision

The rule that makes it a game

A drop within five units of perfect slices nothing and hands width back. Without it the tower could only shrink, and a game you can only lose slowly is a chore.
