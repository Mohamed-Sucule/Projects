The problem

A daily puzzle everyone shares, with no timer and nothing to read first.

What it does

  • A daily board everyone shares
  • Solved means no loose ends, not matching a stored answer
  • A result you can paste into a group chat

The most interesting decision

The board is built backwards

It grows a spanning tree over the grid and reads the tiles off it, so the board is provably solvable before it is scrambled; turning tiles can never make it unsolvable.

Built with

  • Seeded daily boards
  • Canvas 2D
  • Shareable result

Evidence

Everybody in the world gets the same board each day. Read its tests

Its world

Tiles of pipework, turning until nothing is left dangling.
